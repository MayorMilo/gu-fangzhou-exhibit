How to publish your edits
  1. Edit below. Changes autosave as a draft in this browser; use Preview to see them.
  2. Click Download content.js and replace js/content.js in the project.
  3. Best for images: save the file into assets/ and type its path (e.g. assets/letter.jpg). Upload embeds a resized copy inside content.js — fine for a few images, but it makes the file large.
  4. After replacing the file, click Discard draft so previews show the published version.
  5. Commit & push (or upload to GitHub) — the live site updates in about a minute.
